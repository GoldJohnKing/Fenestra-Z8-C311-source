# H.265 码率

**文件** `h265.wlm`，**入口** 设定菜单 → Z8Mouldes → H.265 码率 → 码率。

配套 Nikon Z 8 C3.11 的 `cold-retry3`。复制到卡根目录的 `FENESTRA/` 后完整冷启动。[下载 h265.wlm](https://github.com/PIPA12344/Fenestra-Z8-C311-source/releases/download/wlm-2026.11.10/h265.wlm) · [安装和停用](../z8-usage.zh-CN.md#安装插件)

## 选择 H.265 码率

先选 H.265 文件类型和所需的画面尺寸、帧率，再选 100%（默认）、60%、45%、30% 或 20%。百分比以该模式的原厂标称码率为基准，100% 对应原厂档。菜单中的 Mbps 是目标值，实际录像大小会随场景变化。切换视频拍摄菜单库后可在对应库单独设置。

## 功能来源与移植

本插件使用 NikonFirmwarePatch v0.4.0-rc.2 的对应功能实现，并适配为 Fenestra WLM。[对应源码](https://github.com/XinmiaoZhao/NikonFirmwarePatch/tree/a21fc8c04b6dd863439c4192d387b755633287f6)
